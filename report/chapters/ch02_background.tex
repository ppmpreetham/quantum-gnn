\chapter{Background and Literature Survey}
\label{ch:background}

\section{Introduction}

This chapter introduces the foundations the project builds on, in three
groups: learning (graph neural networks and trust), optimisation (QUBO models,
annealing, tabu search and mixed-integer programming) and systems (the
mist--fog--cloud split, robot middleware and real-time 3D rendering). It then
surveys the closest related work and states the research gap.

\section{Graph Neural Networks}

A graph neural network learns a representation of every node by repeatedly
aggregating information from its neighbours. Kipf and Welling~\cite{kipf2017}
popularised the graph convolutional network and Hamilton
et~al.~\cite{hamilton2017} extended it to inductive settings. Most variants fit
the \emph{message-passing} template, in which node $i$ combines its own state
$h_i$ with an aggregate of its neighbours' states:
\begin{equation}
m_i=\mathop{\mathrm{AGG}}_{j\in\mathcal N(i)} h_j,\qquad h_i'=\phi(h_i,m_i),
\label{eq:bg:mp}
\end{equation}
with a permutation-invariant $\mathrm{AGG}$ and a learned update $\phi$. For
this project two properties of message passing are important. The cost of
inference grows with the number of edges, so a pruned graph needs less work on
the fog device. Also, if messages are weighted by the trust and quality of the
link they travel over, a node can give less weight to neighbours that it cannot
rely on.

\section{QUBO Models and the Penalty Method}

A quadratic unconstrained binary optimisation problem asks for
$z\in\{0,1\}^N$ minimising
\begin{equation}
H(z)=z^{\top}Qz+\mathrm{const}
\label{eq:bg:qubo}
\end{equation}
where $Q$ is a symmetric matrix. Because $z_k^2=z_k$ for binary variables,
the linear terms can be stored on the diagonal. Writing $z_k=(1+\sigma_k)/2$
with spins $\sigma_k\in\{-1,+1\}$ turns the problem into an Ising model, which
is why the same problem can be given to classical, quantum-inspired and quantum
annealers. Formulation techniques are surveyed by Glover
et~al.~\cite{glover2019} and by Lucas~\cite{lucas2014}. Since a QUBO cannot
hold constraints directly, each constraint is turned into a penalty term. An
equality $\sum_ka_kx_k=b$ becomes $\rho(\sum_ka_kx_k-b)^2$, and an inequality
is first given a non-negative integer slack variable, written in binary. The
weight $\rho$ has to be large enough that breaking any constraint never pays
off, and Chapter~\ref{ch:solvers} shows what this safety costs.

\section{Annealing, Tabu Search and Exact Solvers}

Simulated annealing~\cite{kirkpatrick1983} works by proposing small changes.
A change that raises the energy by $\Delta E$ is still accepted with
probability $\exp(-\Delta E/\tau_{\mathrm{SA}})$, and the temperature
$\tau_{\mathrm{SA}}$ is slowly reduced during the run. D-Wave's Ocean
software~\cite{ocean} includes \emph{neal}, a production simulated annealing
sampler. In quantum annealing~\cite{kadowaki1998}, tunnelling driven by a
transverse field takes the place of thermal fluctuations. Simulated quantum
annealing imitates this process on a classical computer, and the OpenJij
library~\cite{openjij} provides a sampler of this kind. Tabu
search~\cite{glover1989} is a local search method that escapes local minima by
forbidding moves made recently. What these four methods have in common is that
they change only a few bits of $z$ at each step, and Chapter~\ref{ch:solvers}
shows that this is exactly what limits them.

A mixed-integer linear program (MILP) has a linear objective, linear
constraints and some variables that must take integer values. Branch-and-cut
solvers such as CBC~\cite{cbc} solve such programs exactly and prove that the
answer is optimal. Requiring a set of nodes to be connected can be written
compactly as a MILP using a \emph{single-commodity flow}: a root node sends one
unit of flow to every required node, and flow may only use selected edges. A
standard result of network-flow theory~\cite{ahuja1993} says that the flows are
integral whenever the data are integral, so the flow variables can be left
continuous.

\section{Fog Computing, Trust and Task Allocation}

Bonomi et~al.~\cite{bonomi2012} introduced fog computing as a layer that sits
between devices and the cloud, so that computation happens close to where the
data is produced, and our deployment uses the same arrangement. Trust and
reputation models judge how reliable an agent is from what it has done before,
and Sabater and Sierra~\cite{sabater2005} review many such models. The simplest
model that is still useful is an exponentially weighted moving average of
outcomes. If trust is estimated without using the graph at all, picking the
most trusted rover becomes a multi-armed bandit problem~\cite{auer2002}. A
trust-only baseline is therefore the strongest simple competitor, and we
include it as a separate baseline. In the
taxonomy of Korsah et~al.~\cite{korsah2013}, our setting has single-task robots,
single-robot tasks and instantaneous assignment, recomputed every cycle.

\section{Robot Simulation and Real-Time Rendering}

ROS~2~\cite{macenski2022} is the standard robot middleware: programs are
\emph{nodes} exchanging typed messages over named \emph{topics}. Gazebo~\cite{koenig2004}
is an open-source multi-robot simulator; its current generation, Gazebo
Harmonic, describes worlds and robots in the Simulation Description Format
(SDF), and a bridge forwards its state into ROS~2. In the browser, WebGL exposes
the GPU and three.js~\cite{threejs} manages scenes on top of it. What matters
most for performance is the number of \emph{draw calls}, because every call
has a fixed cost in the graphics driver. \emph{Instanced rendering} draws many
copies of the same geometry with a single call, and \emph{geometry merging}
joins parts that use the same material into one mesh. Chapter~\ref{ch:engine}
uses both techniques so that the entire fleet is drawn with only a few
calls.

\section{Survey of Related Work}

A number of papers prune the input graph of a GNN. STEP~\cite{li2023step}
trains a self-supervised pruner for large dynamic graphs, but it relies only on
graph statistics and does not use telemetry like trust, link quality or battery
level.
CGP~\cite{liu2024cgp} co-sparsifies structure, features and weights during
training, Wang et~al.~\cite{wang2022} score edges by their effect on the loss,
and Peng et~al.~\cite{peng2022} sparsify GNN weights and structure; all target
model or training efficiency on static benchmarks, and spectral
sparsification~\cite{spielman2011} preserves spectra without hard
constraints. On the allocation side, Ahanger et~al.~\cite{ahanger2023} use a
quantum-inspired optimiser for IoT task allocation across edge and fog nodes,
MAG-Q~\cite{verma2026} combines graph attention, actor--critic learning and
QUBO forwarding for task offloading in fog clusters, and Ali
et~al.~\cite{ali2023} and STMTO~\cite{guo2021} use trust for load balancing and
UAV offloading. Table~\ref{tab:bg:related} summarises them.

\section{Research Gap}

As far as we know, no earlier work combines constrained QUBO pruning with
online trust-aware GNN inference for allocating tasks to rovers. We see three
open gaps. First, existing pruning methods do not enforce hard combinatorial
constraints. Second, trust-aware allocation methods do not spread trust through
message passing. Third, papers that use QUBOs rarely check the solver's output
against an exact solution, so a solver failure can easily be blamed on the
formulation. This project works on all three gaps. It also compares the
pipeline with the strongest classical alternative available, a step that many
proposals leave out.
